## 数据处理

按日期、版面、文章序号聚合，保留原段落顺序。重复编号但内容不同的段落保留并记录。去编号、词性、实体括号，做 NFKC 和控制字符清除，沿用原分词。分类使用标题及正文；词向量上下文按句子/段落组织，不跨文章连接。排除少于 30 词的文章，同标签精确重复保留最早一篇，异标签精确重复退出分类。

使用 64 位字符三元组 SimHash，汉明距离 ≤3 归组；四个 16 位分块索引保证该阈值的候选不漏检，用并查集合并连通组。一月种子 42，20 折 StratifiedGroupKFold 的前 14/中 3/末 3 折合并，得到约 70/15/15。先划分 12 类，再筛选 `01–02`、`01–04`、`01–08`、`01–12`。

## 主实验

| 方法 | 主配置 |
| --- | --- |
| 多数类 | 训练集最多的类别 |
| Gensim TF-IDF | 文档频次至少 3，最高占比 0.9，最多 50,000 词 |
| Gensim LSI | TF-IDF 输入，100 维 |
| Word2Vec | Skip-gram，100 维，窗口 5，最低词频 3，15 轮 |
| Doc2Vec | DBOW，100 维，15 轮；所有分区统一推断 30 轮 |
| Gensim FastText | Skip-gram，100 维，窗口 5，最低词频 3，15 轮，字符子词 1–3，200,000 桶 |
| 原生 FastText | 100 维，25 轮，学习率 0.1，词 bigram，关闭字符子词，softmax，200,000 桶，最低词频 3 |

五种 Gensim 表示接启用类别权重的 LinearSVC，在验证集选择 `C∈{0.1,1,10}`。Word2Vec/FastText 先取词向量均值，再 L2 归一化；无法获得向量的文章使用零向量并统计。原生监督分类每篇一行，标签 `__label__p01`，无编号及词性。

随机模型使用 `42、2026、7`，正式默认 20 个训练线程，固定输入顺序和 Python 哈希种子，多线程不保证逐位确定性。多数类与 TF-IDF 为确定性基线，只运行一次。报告 Macro-F1、Accuracy、逐类 PRF、混淆矩阵、训练时间、峰值 RSS、模型大小和 OOV 覆盖。

## 单因素实验

在一月 12 类训练/验证集，seed 42，每次只改变一个因素。共有配置复用基线缓存。

| 因素 | 取值 |
| --- | --- |
| 维度 | 50、100、200 |
| 窗口 | 3、5、10 |
| 最低词频 | 1、3、5 |
| 轮数 | 5、15、30 |
| 算法 | CBOW、Skip-gram |
| 字符子词 | 关闭、1–3、2–4、3–6 |
| 桶数 | 50,000、200,000、1,000,000 |
| 目标 | 负采样 5、负采样 10、层次 softmax（hs=1、negative=0） |
| 学习率 | 0.01、0.025、0.05 |
| 高频下采样 | 关闭、0.001 |
| 文章向量 | 均值、TF-IDF 加权 |
| 原生词 n-gram | unigram、bigram |
| 速度对照 | workers=1/4/8/20（1 线程仅作速度参照）；batch_words=1,000/10,000 |

TF-IDF 加权时，词典外词使用训练词典最大 IDF。Word2Vec 跳过 OOV，FastText 使用可生成的子词向量。配置选择只依赖验证 Macro-F1；多线程实验用于速度解释，不参加正式模型选择。选定配置用三种子复验。

## 时间扩展与高级分析

冻结一月选定模型评估二月至六月，后续评估排除与一月重叠的近重复组。扩展训练使用一月至四月，五月验证、六月测试；后续分区排除前序分区重叠组。比较 TF-IDF、Gensim FastText、原生 FastText。

阅读[子词向量论文](https://aclanthology.org/Q17-1010/)与[监督分类论文](https://aclanthology.org/E17-2068/)。源码固定 Gensim 4.4.0 / FastText 0.9.2，建立“论文概念—源码位置—运行验证”表，覆盖子词构造、哈希桶、OOV、训练目标、词表过滤、下采样、学习率、迭代、任务队列、线程与批次、保存加载、内存布局和 Python/Cython/C++ 调用。

## 文件与复现

工程入口为 `prepare`、`run`、`report`、`predict`，另有 `evidence` 辅助核验。每次运行保存配置、划分、版本、日志、模型及逐篇预测；按数据、代码、版本和配置指纹复用缓存。文档全部 `.md`，汇总表使用 Markdown，图为 PNG 相对链接，原始指标 CSV/JSON，模型保留原生格式。

依赖固定 `gensim==4.4.0`、`fasttext-wheel==0.9.2`、`numpy==1.26.4`，其余依赖安装验证后精确锁定。Windows wheel 来源记录在源码清单，复现限制据实说明。
