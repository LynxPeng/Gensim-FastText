# 1.1.3 学术改写说明

改写对象为提交报告的“1.1.3 超参数搜索”。新稿采用中文学术文体，补充已有结果的比较依据及解释范围。[修改版](../reports/Gensim&FastText-修改版.md)除该节外与[原报告](../reports/Gensim&FastText.md)相同，原报告保留。训练代码、配置、实验索引及原始数值均未修改。

## 结构与术语

- 节首说明抽样、固定参数、评价分区、逐轮选模与停止规则。
- 训练方式部分区分单种子初筛和三种子复验，结合对照结果、验证轨迹及计算成本解释候选配置。
- 学习率部分分别讨论 Word2Vec 和 Gensim FastText，保留全部种子数值，补充辅助任务与主任务的参数偏好差异。
- 节末集中说明训练预算、语料规模、历史基准观察及全量确认的范围。

| 术语 | 本节约定 |
| --- | --- |
| Gensim FastText | 无监督子词词向量模型，与原生 FastText 监督分类器区分 |
| CBOW／Skip-gram | 两种上下文预测方式，采用 Gensim 的对应训练配置 |
| HS | 层次 softmax；hs=1、negative=0 |
| NS5／NS10 | 负采样；hs=0，负例数分别为 5／10 |
| 初始学习率 α | 线性衰减日程的起始值；终值与轮数上限固定 |
| Spearman ρ | 词相似度排序相关系数；主指标使用固定词表内验证词对 |
| 样本标准差 | 三个训练结果的标准差，分母为 n−1，描述训练波动 |
| 最佳轮次／停止轮次 | 前者选取最高验证分检查点；后者记录实际训练长度 |

## 正文取舍

核心结果为训练方式复验及五档学习率比较；逐轮轨迹、辅助任务与计算成本为必要支撑。负例数接近、较低学习率达到预算上限及基准历史观察属于解释范围，保留在相关段落和节末。缓存复用数量、状态提示和重复风险说明从正文删除，逐次运行数据通过末尾资源链接追溯。原有 11 幅图及两张学习率数值表均保留。

正文按原始索引和 CSV 核对。均值差由未舍入的原始数值计算后统一保留四位小数；标准差采用样本标准差。改写未引入新的实验数值或统计显著性结论，图像未重绘。核对图的实际内容后，耗时图说明限定为累计耗时与平均每轮耗时，内存和文件大小在正文另行报告。
