# THUCNews 小规模训练方式与超参数搜索方案

用户于 2026-10-09 批准将搜索改为小规模，按验证曲线决定是否继续训练。历史全量消融实验保持暂停，资源保留。新入口与历史入口分别保存配置和索引。

## 数据与评价

从已有 821,609 篇清洗、分词、去重后的训练文章中，固定抽取 50,000 篇完整文章。按 14 个类别的训练文章比例分配配额，最大余数法保证总数精确；类别内按文章 ID 和抽样种子 42 的 SHA-256 排名取前若干篇。类别只用于抽样，不作为表示训练标签。保留完整句子/分块及原文章顺序，不跨文章连接。不得抽入已有 5,000 篇留出文章。

固定原有评价划分种子 42 和基准清单哈希，训练种子独立为 42、2026、7。主指标只用 WordSim240 验证集严格词表内 Spearman。预检覆盖率至少 80%；所有配置固定 min_count=5，检查词表、频次和主评价题目覆盖一致。记录失覆盖题，不按评价题补抽语料。FastText OOV 子词生成结果只作辅助诊断。训练和搜索均不计算测试指标。

## 轮数与上升规则

先跑 3 轮；主指标相比上一轮或两轮前提高超过 0.001，视为仍上升。第 3 轮无此上升则停止，否则继续。后续连续 3 轮未超过有效提升参照 0.001、且最近一轮或两轮均无上升时停止，最多 15 轮。最高实际验证分对应最佳检查点，微小上升也可更新最佳检查点。0.001 是预算规则，不是显著性检验，短期噪声可能影响停止决定。

Word2Vec、FastText 独立选轮；每轮保存模型、逐题验证、相关系数、类比指标、覆盖率、耗时及判定理由。学习率按最多 15 轮线性降至 0.0001，早停不重排日程。不记录 loss。最终模型保存加载后的验证指标须一致。

## 搜索矩阵与顺序

| 阶段 | 内容 | 新增训练数 |
| --- | --- | --- |
| 训练方式初筛 | 每模型 CBOW/Skip-gram × HS/NS5/NS10，种子 42 | 12 |
| 训练方式复验 | 每模型基线 CBOW+HS 与最佳新方案，补种子 2026、7 | 8 |
| 学习率完整网格 | 每模型比较 0.005、0.01、0.025、0.05、0.1；每档种子 42、2026、7，共30组 | 复用14组，补充16组 |
| 合计 | 训练方式20组与学习率30组共享6组 | 44次不同配置训练 |

2026-10-10 用户要求至少五档学习率且每档都做三种子，现采用上述完整网格。原三档阶段28组结果保留，其中14组满足新网格并复用，其余16组补充训练。Word2Vec 固定 Skip-gram＋NS5，FastText 固定 Skip-gram＋NS10；不以单种子初筛淘汰学习率，全部五档各三种子完成后，分别按 WordSim240 验证 Spearman 均值选择，完全同分时保留参考0.025，再按学习率升序打破并列。报告样本SD（ddof=1）及全部种子分数，不把三种子解释为消除所有误差。不启动全量学习。

固定 100 维、窗口 5、最低词频 5、下采样 0.001、20 个训练线程、4 个数值库线程、batch_words=9,000、ns_exponent=0.75、CBOW 上下文均值、动态窗口和频次排序。FastText 子词 1–3、200,000 桶。原生参数经模型属性核验。多线程不保证逐位确定性；三种子样本 SD 只描述训练波动。

TF-IDF 保留已有统计对照。子词、桶数、窗口和维度搜索仍是后续独立阶段，本轮不改变这些参数。训练方式阶段仅基线与初筛最佳新方案做三种子，不声称未复验训练方式稳定更差；学习率阶段全部五档均做三种子，仅在各自选定训练方式下搜索，不穷举全部交互。

## 完成后的解释与扩量

本轮仅给出小规模候选，不自动重启旧全量实验。更大规模应复核基线与少量候选，检查配置排名是否稳定；全量模型从头建立词表、初始化权重，并按全量验证曲线重新选轮数。不能照搬小规模最佳轮数，也不能直接比较覆盖题不同的相关系数。最终冻结配置和模型后再统一测试。历史已观察过完整基准，本轮仍属于探索性选参。

```powershell
conda run -n Gensim python -m gensim_lab.thucnews_alpha_grid
conda run -n Gensim python -m gensim_lab.thucnews_small_search --stage stop
conda run -n Gensim python -m gensim_lab.thucnews_alpha_grid --stage audit
conda run -n Gensim python -m gensim_lab.thucnews_alpha_grid --stage report
```

当前使用独立五档网格编排入口，封存结果核验后复用；原三档配置、工作器代码、数据和评价指纹保持不变。新学习率配置从头建立同一词表并初始化权重，不能把已有0.025模型继续训练来冒充新初始学习率。`--stage stop` 请求保存当前完整轮次后停止；编排中断时也会终止训练子进程。只有一个训练编排进程可持有项目文件锁。

矩阵阶段最后一组 FastText／Skip-gram＋NS10／种子 7 曾在第 3 轮中途停止，核对已保存第 2 轮检查点后完整重跑第 3 轮并完成。该历史恢复记录及矩阵阶段配置保留，当前学习率阶段不改写封存的训练结果。

新资源保存于 `artifacts/thucnews_small_search`；抽样清单保存于 `data/thucnews/search_subsets`。冒烟索引与正式索引隔离。配置、数据、代码、版本和评价分区指纹确定缓存，任何变化创建新运行。旧资源 `artifacts/thucnews_ablation` 不修改。

Windows 实时查看进度使用 `tools/read_thucnews_search_progress.ps1`，打开文件时允许删除共享，避免读取窗口阻止 JSON 原子替换。发生文件占用错误时保留日志和已保存检查点，核验后从最后完整轮次恢复；不要把此类 I/O 错误解释为模型未收敛。
