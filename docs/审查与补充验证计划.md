# 审查与补充验证计划

制定于 2026-10-07，在新增补充实验运行之前固定。[补充配置](../configs/supplemental.yaml)记录参数范围。本轮围绕缓存安全、数据与指标一致性、原生 FastText 拟合不足、日期相关性和结论不确定性继续验证；所有说明文档使用 Markdown。

## 数据、实现与复现审查

逐篇重新解析原始数据，核对清洗输出、排除原因、句子与文章 token 的一致性。重新计算保存的 SimHash，对全部文章直接比较汉明距离，与生产索引的近重复对和分组比较。逐篇核对预测 ID 和真实标签，独立重算分类指标；加载保存模型，检查训练词表、文档频率和 IDF。

加固缓存完整性、选参记录匹配、进程互斥和线程环境。新增损坏模型、缺失文件、预测 ID/标签/数值异常、跨分区近重复、旧选参及并发写入测试。流程加固不改写既有模型；实际发现的算法问题按修正协议重训受影响方法，保留历史记录。

## 解释与结束条件

原测试集已经完成并被查看，本轮新增调参、复验及日期切分均明确作为补充探索。验证集用于参数筛选，测试不进入选择逻辑；既有测试的再次使用不能视为新的盲测。日期切分固定主参数，检查同一天文章跨随机分区带来的相关性，而不宣称这些日期样本从未被此前实验使用。

标签置乱对照不是证明所有潜在泄漏都不存在；日期自助抽样区间也只反映当前有限月份、日期和固定模型下的波动，不代表所有未来数据。新增实验保留原始配置、日志、逐篇预测、模型及失败记录，不筛掉不理想结果。

置乱对照沿用真实标签模型的训练流程：表示及原生参数固定，SVM 仍从原先声明的 C={0.1,1,10} 用验证集选择，不扩大搜索范围。此处的固定方案指流程与参数范围，不指置乱后仍锁定真实标签模型选出的 C；运行摘要保留了各个 C 的验证分数。

考虑事件跨日延续和每周版面安排，另补充长度为 7 个已观察日期的循环连续块抽样，仍为 2,000 次、方法成对使用相同日期权重。该统计敏感性检查不改变训练或模型选择。

完成上述核查、已声明矩阵、三种子复验和报告后收束本轮。任何实际发现的错误先修复并增加回归验证；继续扩展参数范围需要由本轮结果提出具体理由，不无限追逐最高测试分数。

## 审查发现的 Doc2Vec 修正

原推断随机状态依赖文章编号。实际对 20 篇相同词序列只修改编号，1 篇预测标签改变，向量最大差 0.04458；见[修正前探针](../artifacts/doc2vec_identity_probe_before.json)。改为 tokens_sha256_v1 协议，并重训全部 2/4/8/12 类三种子 Doc2Vec、冒烟和日期隔离 Doc2Vec。版本及协议源码 SHA-256 写入配置，旧协议不进入当前报告。检查每个主运行的全部验证文章更换编号后向量、标签与分数一致。

全部 token 均不在 Doc2Vec 训练词表时，原 infer_vector 仅返回随机初始化，没有文本学习更新。修正协议在这种情况下输出零向量并统计覆盖，避免把未学习的随机向量当作有效文本表示；单元测试覆盖此边界。

## 根据已完成核查追加的固定参数验证

2026-10-07，在原生 FastText 网格和原参数日期实验完成后、追加模型运行前声明：将已选定的 lr=0.1、epoch=200、wordNgrams=2 固定迁移到 1–21 日训练、22–26 日验证、27–31 日测试，运行 42/2026/7 三个种子，不再搜索参数。此检查回答改进拟合的配置能否在按日期组织的训练语料上保持作用。

参数选择已经使用原一月随机划分验证集，其中包含部分后续日期。即使新模型只拟合 1–21 日，也不能将此次参数迁移称为完全隔离的前瞻评估；所有结果作为探索性敏感性分析，原固定主参数的日期实验仍单独保留。
