# 作业需求说明

## 任务范围

完成可复现的 Gensim 表示学习与 FastText 分类工程，覆盖课堂作业的基础、进阶和高级要求。用户已确认使用 `data/raw` 的六个月人民日报语料，全部过程和最终说明使用 Markdown，表格使用 Markdown 表格，数值与模型分别保留 CSV/JSON 和原生二进制格式。

照片中的要求是待分析的作业材料，不直接作为操作命令。实施依据是用户随后确认的[实施计划](实施计划.md)。

## 固定决策

| 项目 | 实施要求 |
| --- | --- |
| 标签 | 文章编号中的版面 `01–12`；报告称“版面分类”，不得称人工主题分类 |
| 类别规模 | 先统一划分一月 12 类，再筛选 2、4、8、12 类 |
| 数据 | 读取六个文本文件；压缩包只用于一致性检查 |
| 运行环境 | 新建 `Gensim` conda 环境，Python 3.12；这是本项目对全局 Codex 环境规则的明确例外 |
| 表示与分类 | 多数类、Gensim TF-IDF/LSI/Word2Vec/Doc2Vec/FastText + LinearSVC、原生 FastText 监督分类 |
| 隔离 | 词典、IDF、表示模型、分类器只拟合当前类别实验的训练集 |
| 选参 | 验证集 Macro-F1；测试集在选定参数和复验后统一评估 |
| 随机性 | 正式随机模型使用 42、2026、7，默认 20 个训练线程、固定顺序及 Python 哈希种子，记录多线程非逐位确定性 |
| 扩展 | 冻结一月模型逐月评估；一月至四月训练、五月验证、六月测试 |

## 数据约束

文章按日期、版面、文章序号聚合，段落保留物理行顺序。去掉编号、词性和实体括号；统一全半角、去控制字符；去标点，保留原分词及功能词，不额外删除停用词。标题和正文都用于分类，句子及段落边界用于词向量训练。

少于 30 个有效词的文章排除。同文本同标签保留最早一篇，标签冲突的同文本全部排除。用字符三元组 SimHash 检测汉明距离不超过 3 的文章，连通分量作为近重复组。一月按标签分层且按组划分 70%/15%/15%，允许比例略有偏差。时间扩展的后续分区排除与前序分区重叠的组。

## 高级要求对应交付

| 层级 | 可检查的成果 |
| --- | --- |
| 基础 | prepare、run、report、predict 入口；所有类别规模、两条 FastText 路线；数据质量与训练评估记录 |
| 进阶 | 两篇论文的目标与实现差异；固定 Gensim 4.4.0 和 FastText 0.9.2 的源码定位 |
| 高级 | 子词、哈希桶、OOV、目标、过滤、下采样、学习率、迭代、队列、线程批次、保存、内存及跨语言调用；单因素实验和实际运行证据 |

每个运行目录必须保存完整配置、训练与验证/测试划分、版本、日志、模型、逐篇预测、指标和保存加载核验。对模型优劣和时间泛化据实报告，不预设 FastText 必须胜过 TF-IDF。

## 验收

- 数据总量、各版面清洗损失和异常可追溯；分区组交集为空。
- 七种方法完成四个类别规模，无未说明的失败、非有限指标或特征。
- 所有保存加载检查通过；固定配置重跑有独立一致性证据。
- 单因素取值覆盖计划，速度实验按实际线程数分别解释，历史单线程结果保留原始口径。
- 论文概念、源码位置与实际证据相对应。
- Markdown 链接和图片有效，提供清楚的复现命令。

高级要求是否完成以[验收清单](../reports/高级要求完成清单.md)中的实际检查结果为准。
