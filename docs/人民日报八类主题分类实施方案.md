# 人民日报八类主题分类实施方案

本轮按文章内容做政治、财经、科技、体育、娱乐、社会、军事、国际八类主题分类。9801、9802全部用于训练，9803按主题分层、按重复组划为30%验证和70%测试，划分种子42。9804—9806不参与本轮实验。版号仅用于追溯原文，不提供给标注模型或分类器。

全部主题由DeepSeek `deepseek-flash`单次自动标注，关闭思考模式，20个请求并发，每批最多4篇。只对接口或格式失败重试，不增加成功文章的语义复标。保存原文证据、分类依据、自评等级、响应版本和用量。空闲时段预估8—15元，高峰16—30元；总预算35元。价格参考[官方计价](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，查阅日期2026-10-10。凭据从`DEEPSEEK_API_KEY`读取，凭据不写入项目文件。

原生监督部分运行FastText的随机初始化和Gensim FastText向量初始化两条路线。预训练表示保持封存；原生模型在监督训练中更新自己的输入向量，不改变源模型。用户随后增加TF-IDF、Word2Vec、Gensim FastText接同一LinearSVC的比较，复用相同标签和划分，不重新标注；不运行线性Softmax等其他分类头。

原生配置：100维、学习率0.1、minCount=1、词bigram、关闭字符子词、softmax、200000桶、20个CPU线程。种子42在验证集选择5、15、25、50、100、200轮，再用2026、7复验选中轮数。标签与配置冻结后统一评价测试集。指标包括Accuracy、Macro/Micro/Weighted-F1、逐主题Precision/Recall/F1、混淆矩阵、资源成本和保存加载一致性。

自动标签属于弱监督，评价反映模型与该标签体系的一致性，不能当作人工真值上的准确率。三月参与选参，最终结果称为三月留出测试。提交报告只重写1.2，保留1.1及用户其他修改。

冻结表示对照使用[独立配置](../configs/pfr_topic_svm.yaml)：三种文章向量均L2归一化，LinearSVC统一balanced类别权重、L2惩罚、squared-hinge、one-vs-rest和dual=False。每种表示在验证集从C={0.1,1,10}选择Macro-F1最高者，冻结后测试；现有Word2Vec300维、FastText100维，结论不作容量匹配的算法因果比较。另固定选定C运行1—20次求解预算，绘制验证Accuracy曲线；LinearSVC没有逐epoch接口，预算迭代不称为epoch。数值库4线程，特征转换8线程。资源和命令见[复现指南](人民日报主题分类复现指南.md)，结果见[LinearSVC对比报告](../reports/人民日报三种表示LinearSVC对比.md)。
