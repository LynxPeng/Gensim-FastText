# 人民日报固定表示分类复现指南

本轮分类输入为人民日报 9801–9806。THUCNews 仅提供外部预训练的三套表示。全部 Python 命令使用项目 `Gensim` conda 环境。三个源表示原文件保持冻结；不得用旧的全项目报告生成器覆盖用户手工维护的提交文档。

```powershell
# 数据与模型封存校验、固定特征、验证选参、统一测试及逐篇重载核验
conda run -n Gensim python -m gensim_lab.pfr_frozen_classification
# 检查初始原生 FastText 预算不足的探索性补充
conda run -n Gensim python -m gensim_lab.pfr_native_budget
# 生成人民日报结果的科研绘图预览，先检查彩色和灰度成图
conda run -n Gensim python -m gensim_lab.pfr_classification_report --stage preview
# 预览经视觉核验，记录匹配 SHA-256 的 visual_review.json 后导出
conda run -n Gensim python -m gensim_lab.pfr_classification_report --stage export
# 仅替换两份提交报告的 1.2 节，保留 1.1 和后续内容
conda run -n Gensim python -m gensim_lab.pfr_classification_report --stage publish
```

主入口也支持 `--stage prepare/linear/softmax/native/finalize`。完整封存结果会逐文件校验后复用，代码、数据或配置改变会建立新实验目录。测试评价要求全部分类器选参完成，不允许用不完整的矩阵提前选择模型。测试集已有历史观察，本轮比较及扩大预算后的结果均需按报告所述证据范围理解。

总日志为 `artifacts/pfr_frozen_classification/run.log`，补充日志为 `native_budget.log`。`latest.json` 指向当前主实验。实验目录包含 `plan.json`、`split_counts.csv`、固定特征与覆盖率、全部候选模型、验证记录、封存选参、最终逐篇预测、逐类指标、混淆计数、配对 bootstrap 区间和核验。运行目录内 `spec.json` 指明表示、分类器、参数、种子和所属划分。扩展原生模型保存在主实验下的 `native_budget`，不会替换三套表示的主要结果。

Softmax 使用 CUDA；SVM、逻辑回归及原生 FastText 使用其 CPU 实现。原生 FastText 为 20 线程，数值库为 4 线程；固定特征提取使用 8 个线程共享只读模型。三种子复验属于分类训练阶段，不是三个新的预训练表示模型。训练时的标签权重只从对应训练集计算。

预测入口接受已清洗、空格分隔的词序列，与本轮人民日报原分词口径一致。将 `--run` 指向报告结果 CSV 的选定运行目录，例如：

```powershell
conda run -n Gensim python -m gensim_lab.pfr_predict --run artifacts/pfr_frozen_classification/experiments/<实验ID>/runs/<运行ID> --tokens "北京 经济 发展 新闻"
```

输出的版面编号为本模型的预测标签。SVM 的分数为决策间隔，不能解读为概率；Softmax 和原生 FastText 输出最高类别概率。冻结表示和分类头一起构成预测流程，单独复制分类头到新环境时还需保留其源模型及计划文件。
