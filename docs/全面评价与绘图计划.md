# 词向量评价与绘图计划

当前 Word2Vec、FastText 训练分别采用原生 Gensim 和逐轮验证检查点。外部词相似度、类比、OOV、上下文评分等原始历史资源保留；新 THUCNews 实验采用独立验证／测试分区，不能混用完整旧基准结果。

## 指标

| 入口／指标 | 保存内容 | 适用范围 |
|---|---|---|
| evaluate_word_pairs | Pearson、Spearman、双侧 p 值、OOV 比例、覆盖数、逐题余弦 | Word2Vec、FastText；正式指标仅词表内 |
| evaluate_word_analogies | 覆盖题／全部题正确率、关系分组、逐题判断 | Word2Vec、FastText；OOV 按错计入全题 |
| most_similar／similarity／n_similarity／most_similar_cosmul／doesnt_match | 查询结果与词组探针 | 定性诊断，不能代替质量分数 |
| HS score | 留出逐句 score、IV/OOV 词数、上下文事件数 | Word2Vec；FastText 继承路径仅作兼容诊断 |
| 覆盖率与资源 | 词表／可用覆盖率、OOV 次数、时间、RSS、模型体积 | 三种表示；TF-IDF 不参与词向量语义基准 |

HS score 忽略 OOV，只累计窗口中的预测事件，不是整句生成对数概率，不计算困惑度。Doc2Vec DBOW 默认没有联合训练词向量，不用其随机词向量做语义评价。TF-IDF 是稀疏文档表示，不用单词 IDF 充当神经词向量。

## 逐轮验证与检查点

见[THUCNews 方案](THUCNews词向量实验方案.md)。题组去重并固定划分，95 个 WordSim240 验证词对为主指标来源，两个模型分别训练最少 5／最多 15 轮，连续 3 轮无超过 0.001 的有效提升时停止。每轮保存完整原生检查点、全部词对验证指标及固定类比辅助探针；最佳检查点独立重载后才评价全部测试题。原始历史基准已被观察，报告明确这一限制。

## 图型与核查

按 SciPilot 工作流先剖析数据，再确定图型、渲染预览、机器核查与彩色／灰度读图，通过后导出 PNG／SVG。Word2Vec、FastText 各自绘制真实逐轮验证曲线，标记选定轮数；不同辅助指标分面，不用双 Y 轴。方法资源、测试相关系数、类比和覆盖率比较使用条形／差值／构成图；词对关系用逐题散点。单次模型不给重复实验误差棒，不把重叠基准当作独立重复，不按变化幅度阻止绘图。

保存完整精度 CSV/JSON、输入来源和图像哈希。提交报告插入当前曲线和所选模型的测试比较，旧图仅用于历史归档。
