# 人民日报固定表示分类实验方案

本轮分类语料仅使用人民日报 9801–9806（1998 年一月至六月）。THUCNews 只提供已训练并封存的 TF-IDF、Word2Vec 和 Gensim FastText 表示，不使用 THUCNews 类别训练分类器。目标是比较现有三套表示在同一版面预测任务上的效果，而不是据此判定三种算法的一般优劣。

## 数据与划分

复用 `data/processed` 的清洗文本、字符三元组 SimHash 近重复组和一月固定划分，读取前校验原始文本、处理结果和封存指纹。编号、日期和版面 ID 均不进入文本特征；版面 ID 仅作为标签。原始语料已有分词，直接使用清洗后的词序列，不再用 jieba 重新分词。

一月主实验沿用既有训练、验证、测试分区，在统一 12 类划分后分别筛选 01–02、01–04、01–08、01–12。扩展实验用一月至四月训练、五月验证、六月测试；五月中与训练近重复组相交、六月中与训练或验证近重复组相交的文章排除。另将一月 12 类模型冻结，在二月至六月逐月评价，排除与任何一月文章同组的文章。这些评价均不会反过来改变参数。

## 固定表示与统一分类器

TF-IDF 原词典和 IDF 保持冻结。Word2Vec 使用最新 300 维模型，按词次求均值，跳过词表外词；FastText 使用最新 100 维模型，包含能够生成的词表外子词向量。三者均做 L2 归一化，无法表示的文章保留为零向量并统计。每次推理记录词次覆盖、可用向量覆盖与零向量数量。

主要比较使用 LinearSVC，辅助比较使用多项逻辑回归。两者采用类别平衡权重，仅在各自训练集拟合；在验证集选择 `C∈{0.1,1,10}`，以 Macro-F1 为主指标，并列时选择较小的 C。比较同时包含多数类基线。所有候选配置完成验证后统一冻结，随后才进行测试。

## Softmax 与原生 FastText 对照

自行实现的线性 Softmax 接相同的三种固定表示，保持输入表示不更新；含 TF-IDF 的稀疏运算在可用时使用 CUDA。此对照只对一月 12 类和时间扩展分区执行，学习率为 0.001、0.01、0.05，种子 42 初筛；固定最佳学习率后补充 2026、7。AdamW、批次 256、权重衰减 0.0001；至少 10 轮、最多 60 轮，验证 Macro-F1 连续 8 轮未提高超过 0.001 时停止。每轮记录验证结果，保存最佳模型；不增加复杂的训练 loss 记录。

原生监督 FastText 作为额外对照，比较随机初始化和以现有 Gensim FastText 向量初始化两条路线。仅导出对应训练词表中的向量，子词生成的词表外向量可用于初始化。原生模型不导入 Gensim 的字符哈希桶，采用词 bigram、100 维、200,000 桶、softmax、20 CPU 线程；标签联合训练会更新导入的词向量，但不会修改原始 Gensim 文件。种子 42 在 5、15、25 轮中按验证 Macro-F1 选择，固定后补充两个种子。两条路线都使用相同训练数据和原生模型结构。

## 评价与交付

报告 Accuracy、Macro/Micro/Weighted-F1、各版面 Precision/Recall/F1、混淆矩阵、覆盖率、训练与预测耗时、峰值内存和模型大小。对三个表示接 SVM 的测试结果进行配对、版面分层 bootstrap（2,000 次），保存各模型区间与两两差值区间。该区间只描述当前固定测试集的抽样不确定性，不等于表示模型训练种子的波动；Softmax 与原生模型的三种子统计另行报告。

所有模型、预测、配置、版本、划分和检查结果保存为原生格式或 CSV/JSON，说明与报告保存为 Markdown。模型重载后逐篇核对标签和分数；源表示文件重新计算 SHA-256，确认未修改。正文替换提交报告的 1.2 占位内容，保留 1.1 及后续用户编辑。图表显示真实测试指标和误差含义，通过程序及彩色、灰度视觉核验。

当前一月测试分区已有历史实验观察，因此本轮属于固定划分上的探索性比较；不将结果称为新的独立确认性证据。
